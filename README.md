Business Sales & Profit Analytics Dashboard

Project Overview

Created a Business Sales & Profit Analytics Dashboard using Microsoft Excel to analyze sales and profitability.

Key Features

- KPI cards for Total Sales, Total Profit, and Profit Margin
- Region-wise sales and profit analysis
- Product-wise sales and profit analysis
- Category-wise sales and profit analysis
- PivotTables and PivotCharts
- Clean and interactive dashboard design
- Data filtering, sorting, and analysis

Tools & Skills

- Microsoft Excel
- PivotTables
- PivotCharts
- Data Analysis
- Data Visualization
- Dashboard Design
